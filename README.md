# Website Builder Learning Platform

A complete React + Vite project that helps students learn website creation from A to Z.

## What this project includes

- Clean student-friendly UI
- A-Z website section library
- Layout library for different website types
- Section detail pages with examples, do/don't, AI prompt and React code
- End-to-end project creation guide
- Naming rules guide for files, folders, components, variables and routes
- Responsive font size guide for mobile, tablet and desktop
- Style guide for colors, spacing, radius and UI consistency
- UI/UX checklist before production
- SEO + sitemap guide
- Deployment guide
- Prompt library
- Code lab
- sitemap.xml and robots.txt examples

## Run the project

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Folder structure

```txt
src/
├── components/
├── pages/
├── data/
├── utils/
├── App.jsx
├── main.jsx
└── styles.css
```

## Deployment settings

For Vercel or Netlify:

```txt
Build command: npm run build
Output folder: dist
```

## Student learning flow

1. Understand website goal
2. Choose website layout
3. Select required sections
4. Create wireframe
5. Create React project
6. Build reusable components
7. Add responsive UI
8. Check UI/UX quality
9. Add SEO, sitemap and robots.txt
10. Deploy and test live website
