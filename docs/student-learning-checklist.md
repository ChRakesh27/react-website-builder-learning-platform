# Student Website Creation Checklist

## Before coding

- [ ] Write website goal
- [ ] Identify target users
- [ ] Choose layout type
- [ ] List required sections
- [ ] Prepare content for each section
- [ ] Choose colors and font
- [ ] Create rough wireframe

## While coding

- [ ] Create proper folder structure
- [ ] Use PascalCase for component files
- [ ] Use camelCase for variables and functions
- [ ] Use kebab-case for image names and routes
- [ ] Create reusable components
- [ ] Use data mapping where content repeats
- [ ] Keep CSS class names clear

## UI/UX check

- [ ] Check padding and margin
- [ ] Check font sizes
- [ ] Check colors and contrast
- [ ] Check buttons and hover states
- [ ] Check border radius and shadows
- [ ] Check mobile layout
- [ ] Check tablet layout
- [ ] Check desktop layout

## SEO and deployment

- [ ] Add page title
- [ ] Add meta description
- [ ] Use one H1 per page
- [ ] Add image alt text
- [ ] Create sitemap.xml
- [ ] Create robots.txt
- [ ] Run npm run build
- [ ] Preview production build
- [ ] Deploy website
- [ ] Test live website
